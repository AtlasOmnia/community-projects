# AtlasOmnia Community Projects

A source-linked directory of projects shared in the Nous Research Discord's [`#community-projects-showcase`](https://discord.com/channels/1053877538025386074/1316137596535177246).

**Catalog:** 12 projects collected from the Nous Research Discord showcase on **2026-08-27 (UTC)**.

> **Listed, not audited.** Entries reflect information and links supplied by their authors or the linked public project source. AtlasOmnia does not certify security, compatibility, support, licensing beyond what is stated below, or claims made by a project. Review code, release notes, permissions, and pricing before installing or connecting anything to a Hermes environment.

## Contribute an entry

Open a pull request with:

1. The project name and a one-sentence, source-supported description.
2. A public repository, release page, product page, or exact Discord showcase post.
3. The license or availability status when the source states one.
4. A note when a listing is commercial, closed-source, preview-only, or Discord-only.

This catalog is a discovery index, not an endorsement list. Keep each entry factual, concise, and tied to a source the reader can inspect.
